# Thread Pool Monitor

Multithreading custom thread pool manager with live metrics via WebSocket.

## Setup
1. Run \`./gradlew clean build\`
2. Run \`./gradlew bootRun\`

## API Docs
Swagger UI available at: http://localhost:8082/swagger-ui.html

## Tech Stack
- Java 21
- Spring Boot 3.5.16
- WebSocket
- JMX
